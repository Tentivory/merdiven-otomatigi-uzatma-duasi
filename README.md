# Merdiven Otomatiği Uzatma Duası

Bu depo bir yazılım değildir. Bu depo, apartman boşluğunda sönen ışıkla girilen kısa ama ciddi bir karanlık antlaşmasıdır.

Merdiven otomatiği size 37 saniye verir. Siz kapıya 41 saniye uzaktasınızdır. Aradaki 4 saniye ne fiziktir ne de belediye. Aradaki 4 saniye **duadır**.

## Ne işe yarar

`merdiven.py` gerçekten çalışır. Sahte bir merdiven ışığı başlatır, kalan saniyeyi sayar, alkışınızı, fısıltınızı ve “bir saniye” ricânızı değerlendirir. Kapıya yetişirseniz tutanak tutulur. Yetişmezseniz karanlık sizi eşitler.

## Kurulum

Python 3 yeter. Başka bir şey istemez. Ampul hariç. Ampul repoda yoktur, çünkü ampul tarafsızdır.

```bash
python merdiven.py
python merdiven.py --sure 28 --mesafe 6 --alkis 2 --fisilti bir-saniye
python merdiven.py --demo
```

## Bilimsel yöntem

1. Düğmeye basılır.
2. Işık yanar ve hemen pişman olur.
3. Kullanıcı “yetişirim” der. Bu cümle tarih boyunca hiç doğru çıkmamıştır.
4. Alkış, süreye 1.5 saniye ekler. Evren bunu kabul etmez ama yazılım eder.
5. “Bir saniye” demek tam bir saniye etmez. 0.8 saniye eder. Kalan 0.2 saniye komşunun terliğindedir.
